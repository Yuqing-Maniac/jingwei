# 海岛无人值守监视系统
> 岛岸一体感知，微波为主、卫通备份，全天候监视与异常目标处置

## 应用
### 监视指挥层
- 岸基监视指挥中心：态势监视、告警处置、无人机任务调度 {图标:lib:command_center}
- 移动终端 {图标:lib:mobile}

## 传输
- 微波接力站 {装备} {图标:lib:microwave_relay}
- 卫通备份站 {装备} {图标:lib:sat_station}
- 光纤环网 {装备} {图标:lib:fiber}
- 数据链终端 {装备} {图标:lib:comm_tower}

- AIS 接收机 {装备}

## 连接
- 岸基监视指挥中心 <-> 微波接力站 : 微波主链路 [无线]
- 岸基监视指挥中心 <-> 卫通备份站 : 卫通备份 [卫通]
- 岸基监视指挥中心 -> 移动终端 : 告警推送
- 岸基监视指挥中心 -> 无人机机巢 : 巡查任务 [指令]
- 岸基海洋态势云平台 -> 岸基监视指挥中心 : 综合态势
- 岛上边缘计算节点 ~> 微波接力站 : 态势上报
- 岛上边缘计算节点 <-> 光纤环网 [有线]
- 数据链终端 <-> 垂起固定翼无人机 : 数据链 [无线]
- 无人机机巢 -> 垂起固定翼无人机 : 起降 [指令]
- 数据链终端 -> 岛上边缘计算节点 : 视频回传
- 岸基对海雷达 -> 岛上边缘计算节点 : 目标数据
- 光电转塔 -> 岛上边缘计算节点 : 视频
- AIS 接收机 -> 岛上边缘计算节点 : 船舶数据
- 水声监听浮标 -> 岛上边缘计算节点 : 水声数据 [无线]
说明：岛岸之间以微波接力为主链路、卫通为备份，感知数据汇入岛上边缘计算节点，经微波上报岸基海洋态势云平台；监视指挥中心统一研判并向无人机机巢下发巡查任务。

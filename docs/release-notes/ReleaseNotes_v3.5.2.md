# 经纬织图 3.5.2

这一版把审查分支上的图标库和工程内容防护发出去，并把免安装包改成解压后只有一个文件夹和一个入口文件。

## 图标与工程内容

图标库共 655 个写实图标。每个图标有原色、红方、蓝方三种局部涂装，原有编号保留，可以撤销、保存进工程并导出。磁探无人机采用定稿外形：修长机身和翼展，机腹磁探球与前方光电载荷大小接近，四根短支腿只留必要的离地间隙。

图册可以按类别和关键词筛选，并放大查看。检索英文缩写时不区分大小写。

工程里的 HTML 和 SVG 在渲染、属性面板、预览和导出前清理不可信标记。DOMPurify 内嵌在程序里，不需要联网。最近工程写不进浏览器存储时，保留原来的记录并给出提示，不再静默丢掉。

## 怎么打开

解压之后，顶层是 `JingWeiZhiTu` 文件夹和唯一的入口文件。只运行那个入口，不要把入口从文件夹旁边拿走。

- Windows 10／11 64 位：双击 `JingWeiZhiTu.exe`。
- 银河麒麟 V10 ARM64：执行 `sh JingWeiZhiTu.sh`。

第一次运行会在桌面放上「经纬织图」快捷方式，图标与程序一致。Windows 的入口文件和文件夹里的程序都带有图标资源。程序打开后，任务栏使用程序本体的图标。不需要安装，也不需要管理员权限。

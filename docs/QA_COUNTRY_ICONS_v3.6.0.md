# v3.6.0 中美国别外形首轮

本轮覆盖已批准的306项筛选任务，实际接入607个国别外形：303项中美双版本齐备，声呐浮标仅美国版；电子围栏、猛禽驯化拦截保留通用版。原656项通用图标及稳定key保留。

中国默认红色，美国默认蓝色。国别外形和阵营涂装独立保存；换外形采用该国默认涂装，随后可手动改色。老文档未设置外形时维持通用版本。

## 已知外形限制

全部图像均为艺术微缩外形参考，未逐像素测绘。公开平台与虚构任务载荷组合已标 `illustrative-configuration`，不表示该真实平台已实装对应载荷；人物依据公开服装与装备，未通过族裔特征区分国别。

三幅中国构型明确标记“数量细节待修订／待复核”：垂发模块盖数、反坦克车辆发射管数、岸防车箱数。修复尝试未获得可用透明资产，未替换生产图。其他旋翼、起落架、轮数及附件仍应结合参考来源逐图校对。图册展示各批次质量说明。

缺参考的5个国别槽位在catalog中列为pending，未用其他国家的试验外形凑数。电子围栏没有唯一实体；猛禽拦截缺可靠中美外形；中国声呐浮标缺可靠公开轮廓。

## 构建与验证

- 图标注册完整性：306唯一任务、607唯一key/country、1821个透明WebP涂装资产；每个国别模型有公开来源，三种涂装不同，有效蓝色面积不少于可见像素的1%。此阈值只检测技术可重涂性，不保证所有部件面积一致。
- 通用库回归：656项、三种涂装、搜索、撤销与序列化。
- 国别交互回归：面板默认、中国红／美国蓝、手动改色、撤销、保存重开、编队参数、组合拆分、SVG／PNG／PPTX／VSDX导出。
- 语法与桌面入口：Chrome69／Firefox68目标降级、ES2019解析与桌面staging入口检查。
- 单文件图册支持离线检索、类别筛选、三种涂装、深浅背景及打印；网页离线包内含CountryIconAtlas.html。

本轮 `country_catalog_test.cjs`、`country_icons_test.py`、`redrawn_icons_test.py`、`content_safety_test.py`、`downlevel_test.cjs`、`stage_entry_test.js` 均通过。单文件图册实测306张角色卡、检索、缺项占位、配色和主题切换通过。来源链接扫描发现的404已替换并实时复核200。

验证结果以本轮执行日志及测试输出为准。Linux系统Chromium用于界面回归；Windows与银河麒麟原生启动尚待目标机测试，免安装包已按四架构构建。
